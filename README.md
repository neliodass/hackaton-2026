# Secure Software Update System

Monorepo dla projektu konkursowego Kościuszkon 2026 (Honeywell #1) składającego się z aplikacji klienckiej (desktop) i serwera aktualizacji.

## Struktura

- `client/` – Update Client (Python + Tkinter)
- `server/` – Update Server (Python, CLI)
- `shared/` – współdzielone schematy/formaty danych
- `keys/` – materiały kryptograficzne (bez kluczy prywatnych w repo)
- `docs/` – dokumentacja projektu
